# Prompt Patterns

## Universal prompt scaffold
Use this scaffold for most outputs:

```text
Create a [medium] in the Miethe Illustration Constitution.
Primary dialect: [style name].
Optional secondary dialect: [style name].
Feature the canonical family cast: Nick, Wife/Mom, Peyton, Parker, and Penelope.
Exclude dogs unless explicitly requested.
Emotional goal: [goal].
Narrative purpose: [purpose].
Key motifs: [motifs].
Visual priorities: [composition, palette, texture, lighting].
Text to render (if any): [exact text].
Output should feel warm, curious, hopeful, emotionally safe, and specific to the Miethe family.
```

## Book cover pattern
```text
Create a children’s book cover using the Miethe Illustration Constitution.
Primary dialect: [style].
Show the family in a scene that expresses [theme].
Use a literary serif title, a small handwritten note, and 2-4 meaningful motif props.
Keep the composition readable at thumbnail size.
```

## Interior spread pattern
```text
Create a storybook interior spread using the Miethe Illustration Constitution.
Primary dialect: [style].
Show one emotionally meaningful moment, not too many simultaneous actions.
Preserve visual clarity and child-honoring body language.
Use environmental details to extend the metaphor.
```

## App screen pattern
```text
Create a native-feeling app mockup in the Miethe Illustration Constitution.
Primary dialect: [style].
The screen should feel iOS-friendly, warm, and highly legible.
Use the family visual language as illustration and branding, not as decorative clutter.
```

## Poster / infographic pattern
```text
Create a poster or infographic using the Miethe Illustration Constitution.
Primary dialect: [style].
Blend illustration and explanation. Make the result beautiful but useful.
Use titles in literary serif, supporting labels in small caps, and occasional handwritten notes.
```

## Experimental derivative pattern
```text
Create a new derivative style that clearly belongs to the Miethe Illustration Constitution but is not one of the ten named dialects.
State which 2-3 dialects it descends from.
Retain the constitution’s tone, motifs, and child-safe emotional logic.
```
