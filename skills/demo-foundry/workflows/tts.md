# Workflow: Voiceover and TTS

## Goal

Create optional narration without making synthetic voice mandatory.

## Levels

1. Talking points only.
2. Human-recorded script.
3. TTS scratch track.
4. Final synthetic narration.
5. Avatar narration.

## Guidance

Use talking points as the default. Generate a TTS scratch track only if the user requests it or the workflow explicitly enables it.

## Script requirements

- short sentences
- scene timing
- pause markers
- pronunciation notes for product names
- caption-friendly phrasing
- no unsupported claims

## Suggested output files

```text
voiceover-script.md
voiceover-script.short.md
captions.srt
tts-provider-notes.md
```
