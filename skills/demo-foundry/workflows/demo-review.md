# Workflow: Demo Review

## Verdicts

- **Pass**: ready to use.
- **Pass with warnings**: usable with documented caveats.
- **Blocked**: do not use until fixed.

## Review dimensions

1. Correctness
2. Safety
3. Freshness
4. Visual quality
5. Narrative clarity
6. Audience fit
7. Repeatability
8. Artifact completeness

## Required report path

```text
demo/demos/<demo-id>/review-report.md
```
