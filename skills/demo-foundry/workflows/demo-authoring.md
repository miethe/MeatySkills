# Workflow: Demo Authoring

## Goal

Create a new demo scenario.

## Steps

1. Define audience and outcome.
2. Write `demo.yaml`.
3. Create deterministic fixture data.
4. Create Playwright capture script.
5. Capture screenshots and raw video.
6. Write storyboard.
7. Write talking points.
8. Optionally create voiceover script.
9. Optionally render Remotion video.
10. Run review gates.

## Recommended prompt

```text
Use Demo Foundry to create a new demo for this feature. Start with a scenario manifest and Playwright capture script. Generate talking points and storyboard. Do not update project context or workflows unless I approve.
```
