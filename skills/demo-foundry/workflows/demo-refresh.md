# Workflow: Demo Refresh

## Goal

Regenerate an existing demo after product changes.

## Steps

1. Read existing `demo.yaml`.
2. Check app routes and selectors.
3. Re-run seed data.
4. Re-run capture.
5. Compare outputs to prior version.
6. Update storyboard and talking points if UI or claims changed.
7. Re-render videos if needed.
8. Run review gates.
9. Produce refresh report.

## Refresh report should include

- changed screenshots
- broken selectors
- changed claims
- stale narration
- regenerated assets
- unresolved issues
