# Storyboard: Agentic Operating System Overview

## Scene 01 — Why this exists

- Visual: dashboard overview
- Message: goals, task trees, and agents are connected in one workflow surface
- Talking point: "Most agent workflows disappear into chat history. This view makes the work inspectable."

## Scene 02 — Intent tree

- Visual: horizontal task/intent tree
- Message: high-level intent decomposes into executable paths
- Talking point: "The task tree acts like a living execution map, not just a static backlog."

## Scene 03 — Agent roster

- Visual: selected task with agents assigned
- Message: users can see who or what is working on each branch
- Talking point: "Agent assignment becomes visible state instead of hidden prompt history."

## Scene 04 — Evidence and review

- Visual: outputs, traces, review status
- Message: execution produces evidence for review and reuse
- Talking point: "The system can preserve what happened, why it happened, and whether it worked."
