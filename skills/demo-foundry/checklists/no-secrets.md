# Checklist: No Secrets / Privacy

Block the demo if any of these are visible:

- API keys
- tokens
- passwords
- cookies
- authorization headers
- customer names or production data
- real personal information
- private email addresses
- internal infrastructure addresses unless intentionally shown
- unreleased confidential content

Recommended controls:

- seed fake data
- mask sensitive fields
- use `.demoignore`
- review screenshots manually
- scan text outputs
- avoid production accounts
