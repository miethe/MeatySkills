# Integration: Gemini / ChatGPT

## Best use

Use Gemini or ChatGPT for:

- strategy
- audience variants
- narration refinement
- source synthesis
- critique
- GTM copy
- slide insert generation

Use coding agents for:

- repo inspection
- Playwright capture
- Remotion code
- dependency setup
- review gates

## Prompt pattern

```text
Given this Demo Foundry manifest and storyboard, create executive, technical, and operator narration variants. Keep claims grounded in the manifest and mark anything that needs verification.
```
