# Integration: Remotion

## Use Remotion for

- polished demo videos
- zooms/callouts
- captions
- branded browser frames
- title cards
- thumbnails
- duration variants

## Keep components reusable

Recommended components:

- `BrowserFrame`
- `Callout`
- `CaptionBar`
- `CursorHighlight`
- `SceneTitle`
- `ArchitectureOverlay`

## Avoid

- complex one-off animation code for every demo
- manual timeline editing when code can parameterize it
