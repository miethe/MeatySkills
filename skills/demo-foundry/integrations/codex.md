# Integration: Codex

## Recommended usage

Use this pack as project instructions and let Codex modify demo artifacts in a branch/worktree.

Prompt:

```text
Use Demo Foundry. Create a demo-as-code scenario for the current feature. Generate demo.yaml, storyboard, talking points, and Playwright capture script. Do not modify project context or CI.
```

## Best practice

Keep generated demo changes in their own branch or commit so review is easy.
