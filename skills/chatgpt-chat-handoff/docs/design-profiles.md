# CGH design profiles

These presets are portable authored instructions. They are not bundled template binaries,
font files, official corporate standards or evidence that a named asset was uploaded.
The JSON registry is authoritative for exact tokens; the renderer resolves it into each turn.

| ID | Use | Basis |
|---|---|---|
| `work.ibm-consulting-light.v1` | Work slides and technical visuals with a light background | User-preference-based seed; not official compliance |
| `work.ibm-template-exact.v1` | Match a specific supplied IBM/campaign deck | Actual file input and visual references required |
| `personal.fiber-glass.v1` | Opt-in tactile personal app/web concepts | Prior project preference, not a blanket personal theme |
| `personal.editorial-neutral.v1` | Unbound personal editorial work | New neutral fallback proposal |
| `technical.diagram-clean.v1` | Architecture diagrams and coherent icons | New task-neutral preset |
| `custom.inline.v1` | A unique visual constitution or brand | Concrete per-image overrides required |

Explicit task overrides are applied last. `template_exact` binds the actual template rather
than approximating it from a title. The profile's applicable kinds are guidance; custom
cross-kind use should state the intended change. Profile version and selected overrides
belong in the handoff, so repeatability is based on content, not on memory.

For work/personal defaults, the local agent proposes a profile and records it explicitly.
It must not automatically load all of Nick's unrelated personal designs, family details,
confidential branding or old project templates. Select the smallest relevant context.
