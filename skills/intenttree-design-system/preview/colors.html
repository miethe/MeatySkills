Design System · Colors

Color

tokens/tokens.css · v0.1

A muted, semantic palette. Every hue is slightly desaturated so nothing pops harder than it needs to. Color carries meaning — execute, blocked, agent, knowledge — never decoration. Status is always paired with an icon and label so the system stays accessible at high contrast and for color-blind users.

Semantic mapping

Hue → meaning. Always paired with icon + label.

Execute · Complete · On track

Primary CTA, completed nodes, on-track health, ready-to-execute state.

Primary · Selected · Core paths

Selected sidebar item, plan paths, focus rings, primary structural lines.

Agents · Intelligence · Side quests

Agent badges, side-quest dotted outlines, Shepherd assistant moments.

Knowledge · Memory · Context

Knowledge Brain branch, context packets, wiki tiles.

Quick wins · Priority · Attention

Lightning-bolt quick-win chips, priority flags, time-sensitive callouts.

Blockers · Risk · Failure

Blocker warnings, failed agent runs, destructive confirmations.

Milestones · Unlocks

Milestone badges, restraint glow on unlock, achievement markers.

Dashed connectors, archived state, weak/speculative links.
